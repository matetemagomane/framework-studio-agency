# Framework Studio | Agency Website Showcase

The official website for **Framework Studio**, a web design studio specializing in responsive, custom, and visually engaging websites for small businesses, organizations, and e-commerce clients.

---

## 📸 Key Features

- **Hero & Value Showcase:** Eye-catching landing section highlighting agency capabilities and project call-to-actions.
- **Interactive Navigation & Sticky Header:** Smooth-scrolling navigation with dynamic background transitions on scroll
- **Scroll Reveal Animations:** Custom JavaScript triggers smooth entry animations for service cards, project showcases, steps, and testimonials
- **Featured Work Portfolio:** Showcase section featuring completed client sites (Flower Student Residence, Habakuk Empire, Bokamoso Futures Initiative, MK Industrial Crafts, and Kay Accessories).
- **Client Testimonials:** Dedicated feedback section highlighting client success stories
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile devices using CSS Grid, Flexbox, and media queries
- **Direct WhatsApp Integration:** Quick project initiation CTAs linked directly to WhatsApp (`+27723442060`)

---

## 🛠️ Built With

- **HTML5** – Semantic element structure and Remix Icon integration
- **CSS3** – Custom dark-mode styling (`#0b0b0b`), flex/grid layouts, responsive breakpoints, and custom animations
- **JavaScript (ES6+)** – Scroll detection, Intersection Observer patterns via offset calculations, back-to-top button, and navigation tracking
- **Google Fonts** – Poppins typography
